# ⬡ Cia Code

IDE IA nouvelle génération avec **Cia Terminal** intégré.

## Démarrage

```bash
npm install    # installer les dépendances
npm start      # lancer en mode dev
npm run build  # compiler en .exe
click sur Lancia-CiaCode.bat
```

## Configuration IA

Panel IA (droite) → ⚙️ :
- **Clé API** : `sk-...` OpenAI ou compatible
- **Modèle** : GPT-4o, Claude, Llama...
- **Base URL** : OpenAI, Ollama, LM Studio, OpenRouter

## Fonctionnalités

- Éditeur Monaco (moteur VSCode) — thème Cia Dark
- Panel IA compatible toutes APIs
- Cia Terminal — shell multi-onglets (PowerShell / bash)
- Explorateur de fichiers + clic droit
- Tabs multi-fichiers, interface redimensionnable
